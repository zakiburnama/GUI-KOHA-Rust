# Dokumentasi

- [performance.md](performance.md): pengukuran waktu start dan ukuran binary, beserta
  keputusan profil rilis dan keterbatasannya.
- [releasing.md](releasing.md): daftar periksa untuk membuat rilis (prasyarat, pengemasan,
  penerbitan, dan cara membatalkan).
- [platforms.md](platforms.md): keadaan dukungan per OS, dan di mana melanjutkan
  pengembangan untuk Linux dan macOS.

Dokumen lain (instalasi, konfigurasi, kontribusi) ditambahkan seiring pengembangan.
